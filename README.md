## 🎯 ¿Qué es este proyecto?

**PlateMate** es una aplicación diseñada para solucionar el eterno problema al salir a cenar o comer en grupo: **¿quién debe qué?** 
Permite gestionar restaurantes, amigos, cartas de platos (con soporte para carga mediante archivos CSV) y tickets (mediante foto o entrada manual) para calcular de forma justa lo que le corresponde pagar a cada comensal, todo respaldado en la nube con **Google Firebase**.

## ✨ Características Principales

* 🏪 **Gestión de Restaurantes:** Crea nuevos locales o edita sus nombres, según tus visitas.
* 👥 **Control de Amigos:** Añade a tus compis de grupo, edita sus nombres o bórralos fácilmente.
* 📸 **Tickets Flexibles:** Sube una foto del ticket de la cena o introdúcelo de forma manual paso a paso.
* 📋 **Gestión Avanzada de Cartas:** 
  * Añade platos individualmente a la mesa o al restaurante.
  * Modifica o elimina platos existentes.
  * **Importación Masiva:** Sube cartas completas mediante archivos **CSV** o utilizando una plantilla predefinida.
* 🔥 **Base de Datos en Tiempo Real:** Todos los datos de restaurantes, amigos y cuentas se guardan de forma segura y sincronizada en **Google Firebase**.

## 🛠️ Stack Tecnológico

* **Entorno de Desarrollo:** Android Studio
* **Lenguaje:** Kotlin / Java
* **Base de Datos & Backend:** Google Firebase (Firestore / Realtime Database)
* **Gestión de Interfaz:** Jetpack Compose / XML (Views)
